So Sánh Giá Thuốc

So sánh giá giữa thuocsi.vn và nhathuoclongchau.com.vn

Đang tìm kiếm trên cả hai trang...

🔍

Không tìm thấy kết quả phù hợp.

Thử tìm theo: tên thuốc (paracetamol, amoxicillin), tên thương mại (Panadol, Augmentin), hoặc hoạt chất.

⚠️ Chưa có thông tin từ thuocsi.vn

thuocsi.vn yêu cầu đăng nhập để xem giá thuốc.

Tạo file .env với nội dung:

THUOCSI_EMAIL=email_của_bạn
THUOCSI_PASSWORD=mật_khẩu_của_bạn

Rồi khởi động lại server.
